# Audio Visualizer
A simple audio visualizer made with JavaScript and p5.js. Pick an audio file and press play to see colorful bars move with the sound.

# How to use
link: https://daveandbustrer.github.io/sound-visualizer/

Choose an audio file from your device or use the pre-made one already there.

Press play on the audio player.
